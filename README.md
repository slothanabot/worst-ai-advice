One line of the worst possible advice an AI could give — written by a program, in 140 characters or fewer. Entry for make.fun's "Worst AI Advice: The 48-Hour Tight Line Open" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```

The program is deterministic: it writes the same single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) on every run, with no network or model calls.
